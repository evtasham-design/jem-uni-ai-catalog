# AI Services Catalog

Публичная статическая страница-каталог AI-сервисов JEM UNI.

## Что внутри

- `index.html` — основная страница каталога.
- `src/styles.css` — тёмный визуальный стиль по референсам лендинга.
- `src/app.js` — поиск, фильтры, языки, карточки, детали и похожие сервисы.
- `src/data/services.json` — сгенерированная база сервисов.
- `src/data/services-data.js` — встроенная копия данных для статического хостинга.

## Запуск локально

```bash
python3 -m http.server 5177 --bind 127.0.0.1
```

Потом открыть:

```text
http://127.0.0.1:5177/
```

Каталог собран из таблицы `AI_SERVISES.xlsx`: 3 049 сервисов, 13 разделов, три языка интерфейса и описаний.
